# Aurora Café & Co

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------

### Problema da empresa para a criação de um site: 

`Atualmente, a empresa possui apenas um perfil nas redes sociais e recebemos muitos pedidos diretamente pelo WhatsApp. O problema é que estamos começando a perder algumas informações dos pedidos e temos dificuldade para organizar os produtos disponíveis.`

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------

### Objetivo através do problema:

`Organizar as informações dos pedidos para melhorar a facilidade para os usuários `

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------

### Como o cliente deseja o site (área do cliente):

`Gostaríamos de um site moderno, simples de utilizar e que funcione muito bem tanto no computador quanto no celular.`

`Inicialmente, pensamos em algo parecido com uma pequena loja virtual.`

O cliente deverá conseguir:

- **visualizar nossos produtos;**
- **pesquisar produtos;**
- **filtrar por categorias;**
- **visualizar detalhes de cada produto;**
- **adicionar produtos ao carrinho;**
- **alterar quantidades;**
- **visualizar o valor total;**
- **informar seus dados;**
- **escolher uma forma de retirada ou entrega;**
- **finalizar o pedido.**


`Também gostaríamos que o site tivesse uma página inicial apresentando a Aurora Café & Co., uma página de produtos, uma página sobre nossa história e uma página de contato.`

`Quanto ao visual, gostaríamos de algo que transmitisse uma sensação artesanal, acolhedora e moderna, sem parecer um site muito genérico de cafeteria.`

`Ainda não temos uma identidade visual definitiva, então também gostaríamos que o desenvolvedor nos orientasse nessa parte.`


-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------

### Como o cliente deseja o site (área administrativa):

`Também precisamos de uma área administrativa para nossa equipe.`

`Nessa área, gostaríamos de conseguir:`

- **cadastrar produtos;**
- **editar produtos;**
- **excluir produtos;**
- **visualizar os pedidos recebidos;**
- **alterar o status dos pedidos;**
- **visualizar informações dos clientes;**
- **cadastrar e editar categorias.**

`Não precisamos, neste primeiro momento, de pagamento online. O pedido será registrado no sistema e nossa equipe entrará em contato com o cliente posteriormente para confirmar o pagamento e a entrega.`
